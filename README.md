# Sistema de Controle de IPS, Contados, Lojas e Estoque para TI

## Descrição

Este projeto é um sistema de controle que permite gerenciar informações sobre IPS, contados, lojas e estoque. É uma ferramenta útil para profissionais de TI que precisam manter o controle sobre esses elementos.

## Funcionalidades

- **Gerenciamento de IPS**: Controle e monitoramento de endereços IP.
- **Contabilidade**: Registro e acompanhamento de contados.
- **Gestão de Lojas**: Informações sobre lojas e seus estoques.
- **Controle de Estoque**: Monitoramento de produtos e quantidades disponíveis.

## Tecnologias Utilizadas

- **Python**: Linguagem principal do projeto.
- **HTML/CSS**: Para a interface do usuário.
- **JavaScript**: Para funcionalidades interativas.
